# HKOS Benchmarks

Measured on a stock Linux workstation (Python 3.14), deterministic corpus
generated by HKOS itself — no LLM involvement. Numbers come from the
system-level qualification (DS-013/014/015) and are reproducible via
`tests/system` with the documented env gates.

## Retrieval latency

| Corpus | Cold (first query, O(index) parse) | Warm (IndexCache) |
|---|---|---|
| 100 | ~4 ms | ~0.03 ms |
| 10K | <100 ms (SLA) | ~0.03 ms |
| 100K | ~1.1 s (parse, paid once per project/fingerprint) | ~0.03 ms |

Warm retrieval is **2120× faster** than cold (IndexCache, DS-013 Stage 3).

## Pipeline SLA (budgets from DS-013/014)

| Operation | Budget | Measured |
|---|---|---|
| Retrieval (10K, cold) | <100 ms | PASS |
| Context build (10K) | <200 ms | PASS |
| Save (register → canonicalize) | <150 ms | PASS |
| Snapshot load / create / diff | <50 / <300 / <500 ms | PASS |
| Migration detect (100K) | <100 ms | <25 ms (VersionManifest) |
| Migration backup / rollback / validate | <5 / <10 / <10 s | 2.8 / 3.2 / 7.2 s |
| Profiler / metrics overhead | <2 / <1 ms | PASS |

## Index build scaling (the O(N²) fix)

| Knowledge | Before (O(N²) dedup) | After (O(1) set-dedup) |
|---|---|---|
| 10K | 6.8 s | ~0.5 s |
| 20K | 35.0 s | ~1.0 s |
| 30K | 84.6 s | 1.5 s |

Linear after the fix; the 100K build previously did not finish within 285 s.

## Large corpora

- **100K knowledge** (100 projects × 10 campaigns × 1000): generation 19.4 s,
  RAM 85 MB; count/index/snapshot/retrieval consistent first-to-last.
- **1M stress**: mechanism validated at 200K in-session; full run is a
  dedicated window — `HKOS_STRESS_SCALE=1000000`.
- **Long-running**: 3000 cycles (retrieve → context → save → index update →
  snapshot) ≈ 133 s, snapshot versions grow; full 10000 cycles via
  `HKOS_LONG_CYCLES=10000`.

## Crash safety

- `kill -9` mid-write (child process, `os._exit(1)`): exactly the expected
  record count on restart, **zero** `*.tmp*` artifacts, retrieval works after
  `index.build`. All storage writes are atomic (tmp + rename).

## Reproduction

```bash
# system-level tests (env gates keep heavy runs out of default CI)
.venv/bin/python -m pytest tests/system -q
# heavy windows:
HKOS_STRESS_SCALE=1000000 .venv/bin/python -m pytest tests/system -q -k stress
HKOS_LONG_CYCLES=10000   .venv/bin/python -m pytest tests/system -q -k long
```
